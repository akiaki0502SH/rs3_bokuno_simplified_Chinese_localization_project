# 0.1.4 测试建议

先核对输出CRC32为70DB3E30或版本清单中的SHA256，并备份自己的存档。

1. 与罗亚努学院术士对话，检查选人、选术系、法术列表与“算了”取消；确认没有白屏、跳地图或错乱事件。
2. 查看标题动画四屏序文，检查中文、标点及画面切换。
3. 检查正文数字0—9、住宿报价留白及实际扣款。
4. 新开游戏并推进主支线，检查同伴加入／离开、商店仓库、游戏内存取档及少见对白。
5. 自然使用技能和法术，检查名称、说明、战后提示及完整结算。

反馈请附版本、模拟器、地点、动作、预期与实际结果及截图。旧窗口先重开；异常触发后保存的即时档请回到触发前复测。不要上传ROM。
