- 更新IPS/BPS、Windows整合包、参考源码及校验资料；继承v0.1.2及之前修复，旧版标签和附件保留。

住宿数字前导空白及其余排版继续跟进。旧即时档若停在已绘制的窗口，请关闭重开界面或重新触发提示。

- 修正v0.1.1独立字形垂直居中造成的偏高：王、形、阳及同类正文字按统一底部位置排列，60个正文字调整，一、二恢复原字体短笔画设计位置。字号、墨点和横向位置保持。

- 更新补丁、Windows整合包、参考源码及校验资料；v0.1和v0.1.1保留。

文本换行问题继续收集，最后集中修复。旧即时档需重开相关界面以刷新字图；全游戏自然场景仍继续手测。
