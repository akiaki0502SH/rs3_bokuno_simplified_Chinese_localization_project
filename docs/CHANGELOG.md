# 版本记录

## v0.1.1 — 2026-10-12

字体修复测试版，对应内部v288，继承v0.1的译文与功能。

- 修复新中文点阵最右列在部分绘字流程中被后字清掉的问题；原生流程复现旧“吗”缺4点、“娜”缺7点，修复后都完整显示。
- 2673个中文单字全部核对，1719个统一横纵定位，保留笔画形状和字号；原1620个右侧越界风险单字归零。

- 六组正常界面回归、六份游戏档实际载入、独立重建与完整IPS/BPS链核对通过。
- 更新补丁、Windows整合包、工具参考源码及校验资料。v0.1的标签与附件保留。

旧即时档中已经打开的窗口可能缓存旧字图，请关闭再重开该窗口。少数长名称的一格两字仍受字段宽度限制；全游戏自然场景继续验收。
