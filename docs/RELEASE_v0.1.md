# v0.1 · 首个公开测试版

适用于日文Bokuno Proto1.123，累计内容对应内部v287。当前审阅并授权的译文已接入，进入公开游玩测试。

安装顺序：日文RS3 v1.1无头ROM → 作者Bokuno Proto1.123 IPS → 本汉化BPS或IPS。两种汉化格式任选一种，推荐BPS。

- `bokuno_cn_v0.1_windows.zip`：补丁、官方Flips v198、许可证、对应源码和安装说明。
- `bokuno_cn_v0.1_patch.zip`：纯补丁与说明，适合已有工具的玩家。
- `bokuno_cn_v0.1_tools.zip`：可运行的补丁／校验辅助工具及22份汉化实现参考脚本，不是完整独立构建套件。
- `Flips-v198-windows.zip`、`Flips-v198-source.zip`：第三方工具及对应源码，可单独取得。
- `SHA256SUMS`：发行附件校验。

所有本项目包均不包含ROM或私人存档。输出ROM的CRC32为477E6EBF，SHA256为D3F4B6300D811DC9B707CB85286573E43C2EB93DE729DA990AE5AD09ACE20E0E。

完整补丁链与目标逐字节一致。菜单、字体和战斗框做过有限验证；新术自然获取、谢拉哈自然战斗和全流程仍待手测。中文自由姓名输入未提供，少见界面可能仍有漏网文字。请先备份存档并通过Issues反馈版本、场景、复现步骤与截图。
