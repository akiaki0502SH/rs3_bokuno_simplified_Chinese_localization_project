# 已知限制与验收范围

0.1.2是公开测试版。当前审阅并授权的译文已经接入，但尚未完成全流程人工验收。

- 中文自由输入姓名没有作为本版功能提供，保留原输入字符结构。
- 少数历史长名称仍采用一格两字，受原字段宽度限制，本次单字定位修复没有改变这些复字。
- 文本换行问题仍在收集，计划最后集中修复，本版保持现有换行。
- 清单之外的文字、动态提示或少见界面可能仍有日文、错译或显示问题。
- “黑猫”“玻璃之盾”和两条“魔道板解读”的名称已写入，效果与学习规则保持；自然获取、学习及战斗入口仍需玩家测试。

- 32条内部占位或输入结构按结构保留，不把它们当作普通待翻译句子。
- 原生日文RS3存档、其他改造版本或附加补丁组合，没有据此宣称兼容。
